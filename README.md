# English Center Management System - Nancy English Center

Hệ thống quản lý trung tâm tiếng Anh Nancy nhằm tối ưu hóa việc quản lý học viên, giáo viên và điều phối lớp học.

## 🚀 Công nghệ sử dụng
- **Frontend:** HTML5, CSS3 (Flexbox), JavaScript.
- **Backend:** Java (Đang phát triển).
- **Database:** MySQL.
- **Testing:** Playwright (End-to-End Testing).

## 📂 Cấu trúc dự án
- `/frontend`: Giao diện người dùng và trang đăng nhập.
- `/backend`: Xử lý logic nghiệp vụ và API.
- `/database`: Các file thiết kế bảng và dữ liệu mẫu.
- `/tests`: Các kịch bản kiểm thử tự động.
